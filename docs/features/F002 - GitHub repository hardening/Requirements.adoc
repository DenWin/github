= F002 Requirements

== Functional requirements

[#fr-f002-001]
=== FR-F002-001: Explicit repository audit
Status: Implemented

Priority: P1

Source: Protect-GitHubRepository.ps1

The script shall accept an explicit GitHub owner/repository target and shall not infer it from local Git configuration.

[#fr-f002-002]
=== FR-F002-002: Least-friction fork workflow policy
Status: Planned

Priority: P1

Source: Review feedback and GitHub Actions fork-PR approval setting

The script shall audit public repositories for automatic workflows for first-time
contributors who are new to GitHub and shall plan the API-supported least strict
value instead of an unsupported `none` value.

[#fr-f002-003]
=== FR-F002-003: Preserve branch required checks
Status: Planned

Priority: P1

Source: Codex review of branch-protection remediation

When remediating branch protection, the script shall preserve existing
`required_status_checks` configuration and shall not set it to `null`.

[#fr-f002-004]
=== FR-F002-004: Inspect nested push settings
Status: Planned

Priority: P1

Source: Codex review of branch-protection responses

The script shall inspect nested `enabled` fields for force-push and deletion
settings rather than comparing API objects to Boolean values.

[#fr-f002-005]
=== FR-F002-005: Private repository fallback
Status: Planned

Priority: P2

Source: Review feedback

Where the fork-PR approval endpoint is unavailable or unsupported, the script
shall report the setting as Unknown instead of inferring a pass.
