## Stakeholder goals

- **SG-1**: Developers get consistent, safe Git settings across machines and repositories.
- **SG-2**: Repository owners can audit and remediate GitHub security settings.
- **SG-3**: Teams can reproduce repository layouts and manage stale worktrees.
- **SG-4**: Contributors receive fast feedback without weakening main-branch proof.
- **SG-5**: Documentation and automation remain inspectable, traceable and safe.

## Governance

One requirements document is maintained per feature. Requirements use stable
`FR-*` and `NFR-*` anchors and link implementation, tests and specifications
through the feature dossier.
