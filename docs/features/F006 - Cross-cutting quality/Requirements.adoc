= F006 Requirements

== Non-functional requirements

[#nfr-f006-001]
=== NFR-F006-001: No mocks
Status: Implemented

Priority: P1

Source: Pester test suites

Tests shall use real Git repositories and real helper boundaries rather than mocks.

[#nfr-f006-002]
=== NFR-F006-002: Pinned CI dependencies
Status: Implemented

Priority: P1

Source: DevelopmentDependencies.psd1 and CI workflows

PowerShell modules and external Actions shall be pinned to verified versions or commit SHAs.

[#nfr-f006-003]
=== NFR-F006-003: Fail visibly
Status: Implemented

Priority: P1

Source: Invoke-Checks.ps1 and security helpers

Analyzer findings, unresolved security checks and test failures shall produce a non-zero exit result.
